# 蓝河词典（blueos-dict）真机自测清单

## 环境

- 模拟器：BlueOS Studio 预览器（已配置 watch-round 圆表；切 watch-square 复测方表）
- 真机：vivo WATCH 系列，开发者模式 + 调试包（debug rpk）安装

## A. 启动与首页

- [ ] 冷启动 ≤ 2 秒，首页无白屏/卡顿
- [ ] 今日一词展示且为高考词表词；点击进入详情
- [ ] 四入口（背单词/生词本/记录/随机）点击均正确跳转
- [ ] A-Z 索引条在圆屏右缘完整可见，滚动到 Z 后联想列表切换为 z 段词
- [ ] 圆屏四角无内容被裁剪；方表布局无异常拉伸

## B. 查词（重点：输入法）

- [ ] 点输入框拉起手写输入法，手写 "attention"，联想列表出现 attend/attention 等
- [ ] 语音输入（如真机支持）回传文本后联想正常
- [ ] 输入含大写（Attention）联想正常；输入非字母（数字/汉字）回退首页态
- [ ] 点 Go 直接进详情；清空输入回首页态
- [ ] 联想列表滚动流畅（8 条以内，无卡顿）

## C. 单词详情

- [ ] 音标/考级标签/释义/短语/例句渲染完整（验证 abandon、AD、america 三类词）
- [ ] 加入生词本 → 按钮态变"已在生词本"；再点移除
- [ ] 上一个/下一个切换后页面数据整体刷新（含收藏态）
- [ ] 例句缺失的词（如 zoom）不显示例句卡片，布局不塌陷

## D. 背单词卡

- [ ] 高考词源默认 20 张卡；点卡翻转释义；再次点回词面
- [ ] swiper 左右滑动顺滑，进度 1/20 随翻更新
- [ ] 生词本词源：空生词本时显示空态文案；有生词后可刷出卡片
- [ ] 随机词源换一批不重复

## E. 生词本与历史

- [ ] 收藏 2 词后生词本列表展示词+首释义+标签；点行进详情
- [ ] 点"删"仅移除该词，其余保留
- [ ] 最近查询按最新在前排列，重复查询单词去重置顶；清空生效
- [ ] 杀进程重启应用，生词本与历史仍在（storage 持久化验证）

## F. 性能与体积

- [ ] 详情页上一个/下一个连续切换 20 次，无明显卡顿/内存增长
- [ ] 打包 debug rpk，记录实际体积（预期 ≤ 3.5MB；超限执行裁剪预案：砍例句→砍短语）
- [ ] 真机安装后首次启动、查词、翻卡均无 ANR

## 已知风险（验证后记录结果）

- 手写输入法识别英文单词的效率与准确率（交互兜底：A-Z 索引 + 联想）
- 圆屏 A-Z 索引条触控热区是否过小（30px 宽，designWidth 换算后约 0.65mm/px 基准）
- release 包签名与体积（生成证书后复测）
