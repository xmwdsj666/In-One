### 平台硬红线（血泪教训，违反任意一条 = 黑屏/崩溃/错乱，逐条遵守）

1. **模板必须单根**：`<template>` 下只能有一个根节点。多根会让编译器产出空壳模板（无 type 字段），模拟器原生解析直接崩溃（parseDomElement parse json error: no type）
2. **页面数据必须声明在 `data: {}` 对象内**：写在 export default 顶层的字段运行时全是 undefined（框架不认）
3. **禁用 `<block>` 标签**：编译产物带静态 shown:false，内容永不渲染。条件渲染一律用真实组件 + `if` 指令
4. **模板表达式只允许**：字段直绑 `{{ x }}`、`===` 比较、简单三元。**禁用** `!`（取反）、`&&`、嵌套三元、`$item.xxx` 内联传参——全部用 data 里的预计算布尔/字段（可见性集中在一个 syncZones() 方法里维护）
5. **事件传参只用 `onclick="fn($idx)"`** 内联下标形式；`$item` 直接传参、`ev.target.dataset` 均不可靠
6. **`for` 指令只用于 `<list-item>`**（放 text/div 上不渲染）；list/scroll 容器**必须显式定高**（px）
7. **每个模板 class 必须有对应 CSS 规则**：无规则容器默认横排，整页错乱；改完必须断言"模板类名 ⊆ 样式规则"双向一致
8. **横向尺寸慎用 px 定宽**：方表真机/模拟器屏宽 390 < 设计基准 466，固定 px 会整体右溢被裁。优先百分比或以 390 为基准的 px
9. **禁用**：`flex: 1`（官方明令勿用）、`@media`（会被编译器拍平）、`$device` 全局（QuickJS 运行时不存在，onInit 引用即崩）、`device.getInfo` 的 deviceType（手表上只返回 'watch'）、postcss 配置（不被加载）
10. **绝对定位可以但偏移必须全 px**（百分比偏移导致原生崩溃 0xC0000279）
11. **编译产物校验**：`build/<device>/com.<pkg>.vru` 是预览器唯一资源来源，缺失=黑屏；编译后应断言 template.json 根节点有 type 且 children 非空
